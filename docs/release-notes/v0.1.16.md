**Glass looks like glass on more PCs.** On many PCs, Windows' colour settings draw the desktop in 16-bit colour even with HDR off. Oyen Poni took that for HDR and fell back to a flat grey island. Now Glass bends and frosts what's under it there too, and on displays with HDR on, Oyen Poni converts the colours itself. On laptops with two graphics cards, it now finds the one that can copy the screen. Where Glass still can't copy the screen, its stand-in is see-through instead of solid grey.

**The island closes again after you pair a phone.** After a phone finished pairing, the island could stay open for up to 10 minutes, on every page. Now the Shelf's phone panel keeps the island open only while you're on the Shelf and its code is waiting for a phone, and the island says when your phone is paired.

**Install:** download `Oyen-Poni-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Poni\poni.exe`.

**Upgrading from 0.1.x:** run the new installer. It upgrades in place and keeps your settings and data (`%APPDATA%\Poni`).

The build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
