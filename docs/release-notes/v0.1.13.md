**New theme: Glass.** The island becomes liquid glass: its edge bends and magnifies what's under it, the middle is frosted, a light runs along the rim, and it turns light or dark with what's behind it. Pick it in Settings or the tray: **Theme › Glass**.

To draw the glass, Oyen Poni copies the part of the screen behind its window (the island and the space it opens into) while Glass is on, and not while the island is hidden or the PC is locked. The copy stays in your PC's memory, each new copy replaces the last, and it's never saved or sent. While Glass is on, Windows leaves the island out of screenshots, recordings and screen sharing.

Where it can't copy the screen (Remote Desktop, Windows 10 before version 2004, HDR displays, some laptops), Glass draws smoked glass instead: the same shape and light over a solid tint, and it stays in screenshots.

**Oyen dances to your music.** In the Oyen theme, music notes float up beside Oyen on every beat while a song plays, and he sways along. Pause, and the last notes drift away.

**The island stays on top.** When another window covers the island, such as a browser left on top after full screen or an app set to stay on top, the island goes back on top.

**Full-screen apps: Hide or Stay on top.** Games and videos in full screen used to cover the island unless it hid itself. Now you choose: right-click the island, or open Settings, then **In full-screen apps › Hide** or **Stay on top**. Hide stays the default. A game in exclusive full-screen mode still covers every window.

The Mac version's code is in the repository now, as a test build for developers. There is no Mac download yet.

**Install:** download `Oyen-Poni-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Poni\poni.exe`.

**Upgrading from 0.1.x:** run the new installer. It upgrades in place and keeps your settings and data (`%APPDATA%\Poni`).

The build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
