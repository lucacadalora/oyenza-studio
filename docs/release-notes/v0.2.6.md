**The island stays on screen.** In 0.2.4 and 0.2.5, over a maximized window the island stepped aside: it turned invisible and showed only while you pointed at the top edge, so it seemed to vanish when the pointer left. Now it stays where you can see it, in every theme, and the **Over maximized windows** option is gone. To keep the top edge clear, pick **Idle look › Hidden until hover**.

**Oyenza Studio tells you when a new version is out.** About two minutes after it starts, and then every 12 hours, it reads one small signed file from studio.oyenza.com. When a newer version is out, the island says **Update available** with the version and a **Hide** button; click it for the Update sheet with what's new. Until you update, the right-click menu starts with **Update to Oyenza Studio …**. It never looks while the computer is locked, the screen is off or battery saver is on. To turn it off, switch off **Tell me about new versions** in Settings. A copy from the Microsoft Store gets its updates from the Store instead.

**Install from the island (Windows).** Once a new version is out, Oyenza Studio downloads its Setup first (about 2.5 MB), keeps it only if it matches the signed file, and then the Update sheet offers **Install now** or **Install on next start**. Install now closes the island, installs the new version and opens it again; your settings, data, add-ons and Oyenza sign-in stay. On a Mac, the sheet downloads the new DMG.

**A proper Mac installer.** The Mac download opens as an installer window: drag Oyenza Studio into Applications. The version shows in the window's title.

This is the first version that can tell you about the next one. Copies on 0.2.5 or older can't, so update this once by hand.

Everything new in 0.2.5 is here too: your steps from your phone on the Health page, and on the Mac, Oyenza sign-in, headphone pop-ups, stepping aside for full-screen apps and Power. See the [0.2.5 notes](https://github.com/lucacadalora/oyenza-studio/releases/tag/v0.2.5).

**Install:** download `Oyenza-Studio-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Poni\poni.exe`. Links to `Oyen-Poni-Setup.exe` keep working: every release carries that file too.

**On a Mac:** open `Oyenza-Studio-Mac.dmg` and drag Oyenza Studio into Applications. It isn't signed with an Apple Developer ID yet, so the first time macOS warns you, click **Done**, then open **System Settings → Privacy & Security** and click **Open Anyway**.

**Upgrading:** run the new installer. It upgrades in place and keeps your settings, data, add-ons and Oyenza sign-in.

The build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
