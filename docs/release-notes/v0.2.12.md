**Stocks gets its prices.** In 0.2.11 the Stocks tab never asked oyenza.trade for prices, so it kept saying "Getting prices from oyenza.trade…". Now it asks as soon as the tab opens, and the IHSG and your stocks fill in at once; picking **1M**, **6M** or **1Y** brings the chart's year right away too. While it waited, 0.2.11 also woke up to a thousand times a second for nothing (on a Mac it kept a processor core busy); 0.2.12 rests until the next ask.

**On a Mac, updates install in place.** From this version on, a copy in Applications downloads the next version by itself and checks it before the island says **Update available**. Then **Install now** swaps it in and opens it, or it installs the next time Oyenza Studio starts, as on Windows. If anything goes wrong, nothing changes and the download opens for you to drag into Applications as before.

Everything new in 0.2.11 is here too: Stocks, the IHSG and up to 10 IDX stocks on the island, laid out the way Stocks is on a Mac. See the [0.2.11 notes](https://github.com/lucacadalora/oyenza-studio/releases/tag/v0.2.11).

**Install:** download `Oyenza-Studio-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Poni\poni.exe`. Links to `Oyen-Poni-Setup.exe` keep working: every release carries that file too.

**On a Mac:** open `Oyenza-Studio-Mac.dmg` and drag Oyenza Studio into Applications. It isn't signed with an Apple Developer ID yet, so the first time macOS warns you, click **Done**, then open **System Settings → Privacy & Security** and click **Open Anyway**.

**Upgrading:** on 0.2.6 to 0.2.11, the island says **Update available** within a few hours; on Windows, **Install now** in the Update sheet installs it for you. Or run the new installer. Either way it upgrades in place and keeps your settings, data, add-ons and Oyenza sign-in.

The build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
