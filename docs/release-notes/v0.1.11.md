**System page.** A new tab, **System**, sits between Today and Oyenza. It shows your PC's CPU, memory, drives, network and battery, each with the last minute as a chart. Pick one on the left to see more:

- **CPU:** how busy the processor is, how much of that is apps and how much is Windows, its speed, and the three apps using the most.
- **Memory:** how much is in use, how much Windows has committed, and the three apps using the most.
- **Drives:** free space on your drives and how fast they read and write.
- **Network:** download and upload speed, the adapter and your local address.
- **Battery** (laptops): charge, time left, power use, health and charge cycles.

A **Task Manager** button is one click away, and each ring on the Today page now opens its part of the System page.

It reads only while the page is open, once a second, from the same counters Task Manager uses. It needs no driver and no admin rights, and nothing leaves your PC. With the page closed, Oyen Poni still uses no CPU at rest.

**More YouTube songs get lyrics.** Videos whose titles carry subtitle or translation tags ("[Sub Thai]", "Lirik dan Terjemahan", "Vietsub", "【和訳】" and more) now find their lyrics, and so do videos titled "Song - Artist" from channels that name neither. If LRCLIB is busy on one try, the other ways of reading the title are still tried, and songs an older version couldn't find are looked up again now instead of after three days.

**Install:** download `Oyen-Poni-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Poni\poni.exe`.

**Upgrading from 0.1.x:** run the new installer. It upgrades in place and keeps your settings and data (`%APPDATA%\Poni`).

The build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
