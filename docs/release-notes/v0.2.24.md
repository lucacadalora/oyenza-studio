**Claude Code and Cursor on the AI tab again.** If you run Claude Code from the Claude app, the AI tab now shows your Claude plan: it reads the sign-in the Claude app keeps for Claude Code, so Claude Code doesn't need a sign-in of its own on your computer. When Claude Code isn't signed in, its card has a **Sign in** button: it runs Claude Code's own sign-in, `claude auth login`, in a terminal window, or opens the Claude app when that's how you use it. Oyenza Studio never sees your password, and the card shows your plan the next time you open the AI tab. Cursor's numbers are back too: Cursor 3.27 encrypts its sign-in, and the AI tab reads it again.

On a Mac, macOS asks once before the AI tab opens the Claude app's or Cursor's sign-in (the prompt names "security"): choose **Always Allow** and it won't ask again. On Windows nothing asks.

Everything new in 0.2.23 is here too: on a Mac, drag the island along the top edge too. See the [0.2.23 notes](https://github.com/lucacadalora/oyenza-studio/releases/tag/v0.2.23).

**Install:** download `Oyenza-Studio-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Poni\poni.exe`. Links to `Oyen-Poni-Setup.exe` keep working: every release carries that file too.

**On a Mac:** open `Oyenza-Studio-Mac.dmg`, drag Oyenza Studio into Applications and open it. macOS asks once whether to open an app downloaded from the internet: click **Open**.

**Upgrading:** the island says **Update available** within the hour on 0.2.13 to 0.2.23, and within half a day on 0.2.6 to 0.2.12; **Install now** in the Update sheet installs it for you. On a Mac, a copy older than 0.2.12 downloads the DMG instead: open it and drag Oyenza Studio into Applications. If macOS doesn't let a copy replace itself, it opens the DMG for you to do the same. Either way it upgrades in place and keeps your settings, data, add-ons and Oyenza sign-in.

The Windows build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
