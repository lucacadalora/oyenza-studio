**The Mac app is signed and checked by Apple.** Oyenza Studio for Mac now carries an Apple Developer ID signature, and Apple has checked it for malicious software (notarized). The first time you open it, macOS only asks whether to open an app downloaded from the internet: click **Open**. No more trip to System Settings › Privacy & Security › Open Anyway.

**Your Mac's permissions, one more time.** macOS ties what you allowed, such as Music, Spotify and your location for Prayer times, to the app's signature. So this first signed version asks for them once more. From now on, updates keep them.

On Windows nothing changes: this version is 0.2.14 with the Mac signed. Everything new in 0.2.14 is here too: the island stays open under its right-click menu, new versions are always looked for, and Bluetooth pop-ups come only for your headphones. See the [0.2.14 notes](https://github.com/lucacadalora/oyenza-studio/releases/tag/v0.2.14).

**Install:** download `Oyenza-Studio-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Poni\poni.exe`. Links to `Oyen-Poni-Setup.exe` keep working: every release carries that file too.

**On a Mac:** open `Oyenza-Studio-Mac.dmg`, drag Oyenza Studio into Applications and open it. macOS asks once whether to open an app downloaded from the internet: click **Open**.

**Upgrading:** the island says **Update available** within the hour on 0.2.13 and 0.2.14, and within half a day on 0.2.6 to 0.2.12; **Install now** in the Update sheet installs it for you. On a Mac, a copy older than 0.2.12 downloads the DMG instead: open it and drag Oyenza Studio into Applications. If macOS doesn't let a copy replace itself, it opens the DMG for you to do the same. Either way it upgrades in place and keeps your settings, data, add-ons and Oyenza sign-in.

The Windows build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
