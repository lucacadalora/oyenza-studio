**Your browser's tabs stay visible.** Over a maximized browser, the island now steps aside instead of sitting on its tabs. The same goes for any window whose top edge is at the top of the screen, such as one snapped to half the screen. The clock or the song waits out of the way, and only an invisible strip stays along the middle of the top edge, so the tabs show and take clicks. Point at the top edge to open the island. The volume, battery and Bluetooth pop-ups, notices and a new song's title still show for a few seconds. To keep the island over those windows, right-click it › **Over maximized windows** › **Stay**, or pick **Stay** next to **Maximized windows** in Settings. This is Windows only: on a Mac the menu bar already keeps windows below the island.

Everything new in 0.2.3 is here too: the reading in Latin letters under each sung line on the closed island, and Prayer times on the Mac. See the [0.2.3 notes](https://github.com/lucacadalora/oyenza-studio/releases/tag/v0.2.3).

**Install:** download `Oyenza-Studio-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Poni\poni.exe`. Links to `Oyen-Poni-Setup.exe` keep working: every release carries that file too.

**On a Mac:** open `Oyenza-Studio-Mac.dmg` and drag Oyenza Studio into Applications. It isn't signed with an Apple Developer ID yet, so the first time macOS warns you, click **Done**, then open **System Settings → Privacy & Security** and click **Open Anyway**.

**Upgrading:** run the new installer. It upgrades in place and keeps your settings, data, add-ons and Oyenza sign-in.

The build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
