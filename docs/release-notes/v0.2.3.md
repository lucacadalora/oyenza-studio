**Sing along from the closed island.** While a Japanese, Korean or Chinese song plays, the closed island now shows each line's reading in Latin letters right under it: romaji, the Korean syllables or pinyin, in every theme, on Windows and Mac. Until now the reading showed only on the Music page. For these songs the island is two rows tall for the whole song, so it doesn't grow and shrink line by line. Songs that need no reading keep the one-row island, and switching off **Lyrics pronunciation** in Settings brings it back too.

**Prayer times on the Mac.** The Mac's Add-ons tab now has Prayer times, as on Windows: Location Services finds your kab/kota, or you type it, and the island counts down the ten minutes before each prayer and plays the adzan when it's time. Around a MacBook's notch the countdown sits beside the camera, the moon on the left and the minutes on the right. The Mac app grows by about 70 KB.

**Install:** download `Oyenza-Studio-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Poni\poni.exe`. Links to `Oyen-Poni-Setup.exe` keep working: every release carries that file too.

**On a Mac:** open `Oyenza-Studio-Mac.dmg` and drag Oyenza Studio into Applications. It isn't signed with an Apple Developer ID yet, so the first time macOS warns you, click **Done**, then open **System Settings → Privacy & Security** and click **Open Anyway**.

**Upgrading:** run the new installer. It upgrades in place and keeps your settings, data, add-ons and Oyenza sign-in.

The build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
