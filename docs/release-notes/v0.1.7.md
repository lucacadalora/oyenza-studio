**The Oyen theme, all the way through.** Until now the Oyen theme only brought Oyen and his orange into the black island. Now it changes the whole island:
- **Colours:** a warm cream island with dark brown text, and Oyen's orange on the play button, the progress and volume bars and the switches.
- **Font:** every Latin letter is set in Outfit, the Oyen Poni website's typeface, which now ships inside the app.
- **Oyen:** he also peeks up beside the pin when the island is open, eyes on your cursor.

Classic looks exactly as before. Choose either from the tray menu: **Theme → Classic / Oyen**.

**Lyrics that keep time with Apple Music.** Apple Music for Windows tells other apps where a song is about half a second late, and in jumps, so synced lyrics trailed the singing. Lyrics now run on their own steady clock that rides out the jumps, half a second ahead for Apple Music. If they still feel early or late for you, set `lyrics_offset_ms` in the settings file (tray → Open settings file). Positive values show each line earlier, for example `300`.

**Read along in Japanese, Korean and Chinese.** Like Apple Music's "Show Pronunciation", each word or phrase of a lyric line now has its reading in Latin letters set small under it:
- **Japanese:** romaji, read with Windows' own Japanese reading analyzer (part of Windows, no download).
- **Korean:** the syllables under each word, spaced the way Apple Music shows them.
- **Chinese:** pinyin with tone marks.

Turn it off in the tray menu: **Lyrics pronunciation**.

**Install:** download `Oyen-Poni-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Poni\poni.exe`.

**Upgrading from 0.1.x:** run the new installer. It upgrades in place and keeps your settings and data (`%APPDATA%\Poni`).

The build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
