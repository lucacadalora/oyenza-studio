**On a Mac, Oyenza Studio opens again.** 0.2.0 and 0.2.1 quit the moment they started on some Macs, with nothing on screen, because reading the graphics card's memory failed on Macs whose graphics don't report it. That reading is now skipped when it isn't there, and the island and the menu bar icon come up as they should. If you installed 0.2.0 or 0.2.1 and nothing happened, install this one over it.

Everything new in 0.2.1 is here too: the Script reader add-on, Show over games staying over the game, Power on the System page, lyrics on the closed island in every theme, Japanese readings switching themselves on and the Prayer page's countdown. See the [0.2.1 notes](https://github.com/lucacadalora/oyenza-studio/releases/tag/v0.2.1).

Nothing changes on Windows.

**Install:** download `Oyenza-Studio-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Poni\poni.exe`. Links to `Oyen-Poni-Setup.exe` keep working: every release carries that file too.

**On a Mac:** open `Oyenza-Studio-Mac.dmg` and drag Oyenza Studio into Applications. It isn't signed with an Apple Developer ID yet, so the first time macOS warns you, click **Done**, then open **System Settings → Privacy & Security** and click **Open Anyway**.

**Upgrading:** run the new installer. It upgrades in place and keeps your settings, data, add-ons and Oyenza sign-in.

The build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
